# Ôn Tập Kiến Trúc Máy Tính & Bảo Trì Máy Tính

## Giới thiệu

Trang web ôn tập cuối kỳ cho môn **Kiến Trúc Máy Tính (KTMT)** và **Bảo Trì Máy Tính (BTMT)** - 4 tín chỉ.

## Tính năng

### 🎯 Nội dung KTMT
- **Chương 1: Số học máy tính**
  - Biểu diễn số nguyên, số thực trong máy tính
  - Mã phát hiện và sửa lỗi (Parity, CRC, Hamming)
- **Chương 2: Tổng quan về máy tính**
  - Nguyên lý Von Neumann
  - Sơ đồ tổ chức tổng quát
  - Bus hệ thống
- **Chương 3: Tổ chức hệ vi xử lý 8088**
  - BIU (Bus Interface Unit)
  - EU (Execution Unit)
  - Các thanh ghi đa năng, đoạn, cờ
- **Chương 4: Kỹ thuật ống dẫn & Bộ nhớ**
  - Pipeline (kỹ thuật ống dẫn)
  - Bộ nhớ Cache (L1, L2, L3)
  - ROM, RAM, DRAM

### 🔧 Nội dung BTMT
- **Phần 1: Cấu tạo máy vi tính**
  - Mainboard, CPU, RAM
  - PSU, HDD, SSD
- **Phần 2: Lắp ráp & Tính tương thích**
  - Nguyên tắc chọn thiết bị
  - Quy trình lắp ráp
- **Phần 3: Bảo trì máy tính**
  - Kế hoạch bảo dưỡng
  - Sao lưu dữ liệu
  - Phòng chống virus

### 🧮 Công cụ tính toán
- Chuyển đổi Decimal ↔ Binary ↔ Hex
- Tính IEEE 754 Single Precision
- Tính mã CRC
- Tính mã Hamming
